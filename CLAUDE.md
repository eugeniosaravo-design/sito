# Sito di Eugenio Saravo

Sito statico in HTML, CSS e JavaScript, senza build. Si pubblica da solo con GitHub Pages dal branch `main`.

- Eugenio non scrive codice: spiegagli le cose in italiano semplice e mostra il risultato.
- Il repository è pubblico: niente preventivi, contratti o materiali riservati.
- Usa sempre percorsi relativi. Il sito deve funzionare sia sul dominio sia sotto `/sito/`.
- Dopo il collegamento del dominio, il file `CNAME` non va toccato. Non cambiare mai i record MX o TXT di Zoho.
- I testi del sito sono in inglese.
- Immagini in `assets/img/`, formato WebP, nome `progetto-LARGHEZZA.webp`.
- Home: i lavori principali sono blocchi `.work-frame` a tutto schermo, gli altri sono quadrati `.square`. `data-stills` elenca i frame che scorrono col mouse.
- I video restano su Vimeo, YouTube e Instagram. Non caricare file video nel repository.
- Font: Archivo, licenza OFL, ospitato in `assets/font/`.
